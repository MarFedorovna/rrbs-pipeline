# Проверка проекта

Проверено локально 29.10.2026 в Linux / WSL2 Ubuntu 22.04, в окружении из включённого `environment.linux-64.lock.txt`.

## Выполнено

- Пять автоматических проверок: порядок/группы образцов, отказ при повторе ID, контроль MD5 и повреждённых локальных источников, фильтрация хромосом и сохранение координат, промоторы обеих цепей.
- Полный технический прогон с настоящими программами: FastQC → Trim Galore → Bowtie2/Bismark → methylation extraction → methylKit → аннотация → GO → MultiQC → provenance.
- Искусственный набор: 4 paired-end образца по 2000 пар, референс 12 500 bp. Проверены 727 CpG и 13 фиксированных окон. Получено 726 гиперметилированных тестовых позиций и 0 гипометилированных: это соответствует намеренно заложенной разнице тестовой и контрольной групп.
- Аннотация сопоставила 5 искусственно размещённых генов; выполнены 275 GO-тестов для позиций и 275 для окон. GO FDR <0,05 не обнаружен, что корректно: весь маленький фон оказался выбранным.
- Созданы четыре HTML-отчёта Bismark, MultiQC HTML, QC PDF, таблицы, BED и provenance. Проверены их наличие, структура и ожидаемое направление эффекта.
- Повторный dry-run тестового запуска подтвердил, что все результаты актуальны и пересчитывать их не нужно. Проверка плана для четырёх реальных образцов построила 47 задач без скачивания данных. Предварительная проверка всех программ и R-пакетов прошла.
- Отдельный запуск `scripts/prepare_data.sh` в чистой копии проекта прошёл на искусственных данных: проверены MD5 восьми FASTQ, созданы 12 файлов индексов Bismark и три BED-аннотации. Выравнивание и статистика при подготовке не запускались. Повторный запуск подтвердил актуальность готовых файлов. План подготовки реального набора содержит 15 задач.

Для технического теста использована BH-коррекция и отключён верхний coverage-фильтр, поскольку искусственные повторы имеют почти одинаковое покрытие. Основной конфиг реальных образцов использует `qvalue` и 99,9-й перцентиль. PCA использует все подходящие позиции маленького теста; на больших данных — воспроизводимую подвыборку до 100 000 CpG.

Окружение фиксирует `r-data.table=1.16.4`: новые версии удалили экспорт `key<-`, необходимый methylKit 1.32.0. Bismark 0.25.1 не принимает явно заданный `-p 1`; workflow в этом случае использует его однопоточный режим по умолчанию. Полные версии и сборки сохранены в lock.
